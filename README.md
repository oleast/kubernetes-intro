# kubernetes-intro

Workshop for å bli kjent med kubernetes

## Før du starter

Du trenger:

- [Homebrew](https://brew.sh/)
- [gcloud CLI](https://cloud.google.com/sdk/docs/install)
- Tilgang til GCP-prosjektet (spør workshopholder om å bli lagt til)
- `kubectl` (installeres i oppgave 1)
